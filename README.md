# 🎵 Spotify UI Clone

Uma recriação visual da interface do Spotify, desenvolvida com **HTML, CSS e JavaScript**. O projeto busca reproduzir a identidade visual da plataforma original, incluindo sua organização, seus elementos gráficos e a disposição dos conteúdos em uma única página.

## 📌 Sobre o projeto

O Spotify UI Clone é um projeto de Front-End focado na reprodução de uma interface já existente, utilizando tecnologias fundamentais do desenvolvimento web.

A página apresenta uma estrutura inspirada no Spotify, com navegação lateral, barra de pesquisa, seções de artistas e álbuns, além de elementos interativos e efeitos visuais.

## 🚀 Funcionalidades e características

- Interface inspirada no design original do Spotify.
- Sidebar com navegação lateral.
- Barra de pesquisa estilizada.
- Seção de artistas com cards gerados dinamicamente.
- Seção de álbuns com imagens e informações.
- Efeitos de hover e transições suaves.
- Animações interativas nos botões.
- Organização dinâmica de conteúdos utilizando JavaScript.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização, responsividade visual, Grid, Flexbox, transições e efeitos.
- **JavaScript:** manipulação do DOM, arrays de objetos, criação dinâmica de elementos e eventos.

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos importantes de desenvolvimento Front-End, principalmente:

- Manipulação dinâmica do DOM.
- Utilização de `createElement()`, `appendChild()` e `innerHTML`.
- Iteração de dados com `forEach()`.
- Organização de informações utilizando arrays de objetos.
- Estilização e interatividade com CSS.
- Aplicação de efeitos visuais e transições.

## 🎯 Objetivo

Praticar e consolidar conhecimentos em HTML, CSS e JavaScript por meio da reprodução de uma interface conhecida, desenvolvendo habilidades de estruturação, estilização e manipulação dinâmica de elementos.
